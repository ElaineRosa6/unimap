## 必须保留的安全边界

自动“发现变化 → 证据截图 → 图片通知”没有启用。现有调用前 URL 检查只能验证初始目标，
不能阻止 Chrome 或 Extension 在导航期间访问跨主机重定向目标，也不能完整抵御 DNS
rebinding。

启用自动证据截图前必须完成：

1. 对浏览器每次导航、重定向和子资源请求执行目标校验；
2. 将实际连接地址与校验结果绑定，避免解析后地址变化；
3. 同时覆盖 CDP 与 Extension 路径，禁止私有、loopback、link-local 和内部地址；
4. 增加重定向、DNS rebinding、IPv4/IPv6 和资源加载绕过测试；
5. 通过安全复核后，再接通巡检证据截图和图片通知。
